    Questions
    
    
    Good to know.
    
  
    
  
    
    
    Is Orion Terminal free?
    Yes. The public alpha is free and the code is open source. If you connect an AI provider, that provider's own subscription or API pricing applies.
    
    
    Which Macs does it run on?
    Macs with Apple Silicon (M1 or newer). There's no Intel, Windows or Linux build yet.
    
    
    Do I need an AI subscription?
    No. Notes, code and design all work without AI. To use the assistants, connect an account you already have in Control Panel → Providers. Inline code edits and Tab autocomplete use an Anthropic API key, which is billed separately from subscriptions.
    
    
    Where is my data stored?
    On your Mac, in a local database with automatic backups. There's no Orion cloud. Local data isn't encrypted, so treat it like any other files on your computer. When you use AI, the content you send goes to the provider you chose.
    
    
    Why does macOS warn me when I first open it?
    The alpha is signed but not yet notarized by Apple. Approve only a download you trust, using Open Anyway in Privacy & Security. Please don't turn off Gatekeeper.
    
    
    What does “alpha” mean here?
    It's early. The core apps are ready to use, but some features, like FX, video and 3D tools, are experimental. Accessibility work is still in progress. Back up important work and report anything odd.
