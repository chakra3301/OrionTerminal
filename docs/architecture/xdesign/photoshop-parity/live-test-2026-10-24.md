# Live test: Photoshop 2026 vs XDesign photo (2026-10-24)

The two apps were driven side by side on the owner's Mac, with the same scratch image (`xd-ps-test.png`, 1200×800) open in each. Every check opened the same menu item, dialog or tool in both apps and compared screenshots. The owner's own documents were not touched; the scratch documents were closed without saving.

Colours were ignored, as the owner asked. The test compared which controls exist, how they are laid out and how they behave.

Companion docs: [dialogs.md](dialogs.md), [menus.md](menus.md), [panels.md](panels.md), [tools.md](tools.md).

## Fixed during the test

1. **Layer Style layout** (`layerStyleDialog.css`).
   - Older generic `.xd-photo-dialog` rules in `photo.css` were leaking into the dialog:
     - the list text was centred;
     - each slider row stacked its label, slider and field;
     - "Use Global Light" and "Anti-aliased" wrapped;
     - the Contour dropdown collapsed to zero width.
   - The list's `flex:1` also stretched "Styles" and "Blending Options" to fill the column.
   - Now: label, slider, field and unit sit on one row, as in Photoshop.
2. **Layer Style: Esc did nothing after any click in the dialog** (`LayerStyleDialog.tsx`).
   - In WebKit on macOS, clicking a `<button>` does not focus it, so focus left the dialog. The dialog's scrim `onKeyDown` therefore never saw Esc.
   - Layer Style and New Style now use the shared `useDesignDialog`, like every other photo dialog: a window-level Esc listener, the dialog stack and a focus trap.
   - Checked live: Esc after a list click cancels. With the color picker open, the first Esc closes only the picker.
3. **Bevel & Emboss labels** now read "Highlight Mode" and "Shadow Mode" instead of two "Blend Mode" rows.

## P0: broken behaviour

- **Shortcuts only work while the canvas stage has focus.**
  - The handler is on `section.xd-photo` (`PhotoStudio.tsx`), which has no `tabIndex`.
  - After a click on a tool, a panel or the doc tab, focus is on `body`. ⌘L then opens R.O.S.I.E (`src/commands/builtins.ts`) instead of Levels, and other keys do nothing.
  - Photoshop shortcuts work from anywhere except text fields.
  - Candidate fix: `tabIndex={-1}` on the section, or a window-level listener scoped to the active photo window.
- **Shell accelerators overlap Photoshop shortcuts.** ⌘L (R.O.S.I.E) clashes outright. The native menu's ⌘M, ⌘W, ⌘H and ⌥⌘M are potential clashes with Curves, Close, Hide Extras and others.
- **Shadows/Highlights is taller than the window.** It always shows every option, and the lower controls can't be reached on a short window.

## Not covered

Both items were compared with Photoshop 2026 afterwards, using its bundle layouts (`layers_panel.eve`, `Channels/Paths/History.exv`, `cropOptionsFlyout-2381.exv`), its binary strings and `Default Keyboard Shortcuts.kys`. At first only the unit tests had run; the live check is in the last section.

- **Panel internals:**
  - **Layers:**
    - clipped rows show the clip arrow, and the base layer's name is underlined;
    - the badge is a solid lock for Lock All, an outline lock for partial locks;
    - lock, footer and filter tooltips use Photoshop's text;
    - "Create new fill or adjustment layer" opens Solid Color…, Gradient…, Pattern…, then the adjustments;
    - a Group filter mode;
    - Rename Layer… and Hide/Show Layers in the flyout.
  - **Channels:**
    - thumbnails for every row (a new read-only native command);
    - ⌘2–⌘9 labels and shortcuts;
    - load-as-selection for composite, colour and alpha channels, by button or ⌘-click, with Shift/Option/Shift+Option;
    - Photoshop's flyout labels.
  - **Paths:**
    - SVG thumbnails and the italic Work Path;
    - the Photoshop footer, including Add a mask (a vector mask) and Create new path;
    - the flyout, including Duplicate Path… and Clipping Path….
  - **History:**
    - the snapshot row;
    - the History Brush source column;
    - the footer;
    - Photoshop's flyout order.
  - **Properties for adjustment layers** already matched.
- **Number keys:**
  - with a tool that doesn't paint, 1–9 and 0 set the layer's Opacity, and Shift sets Fill;
  - two quick digits give an exact value;
  - with Airbrush on, digits set Flow, and Shift sets Opacity.
- **Already matched:** scrubby labels and the undo depth (50 states).
- **Still missing, with the reason:**
  - **No engine support:**
    - Layers' artboard auto-nest lock, the Color and Artboard filter modes, and the Cleanup button;
    - History's New Snapshot, New Document from state, Delete state, Clear History and History Options (shown, but disabled).
  - **No dialog:**
    - Panel Options… on Channels and Paths;
    - the dialogs behind Duplicate Channel/Path and Clipping Path flatness. These act at once instead.
  - **Behaviour differences:**
    - two quick digits record two history steps;
    - Add a mask doesn't become Add vector mask on a second click.

## Live pass of the panel-internals round (evening, 2026-10-24)

Everything under "Not covered" above was then checked in the running dev app on the scratch project. PROGRESS.md's "live pass of the panel-internals round" entry lists the fixes file by file.

**Matched Photoshop once checked:**
- **Layers:** lock badge, footer, tooltips, and the fill/adjustment popup's list and grouping.
- **Channels:** thumbnails, ⌘-digit labels and targeting. ⌘3 shows Red and the doc tab reads "Red/8#".
- **Paths:** footer and the Work Path thumbnail.
- **History:** footer.
- **Number keys:** they set Opacity.
- **Crop:** Show Cropped Area, H, / and X.
- **Rulers:** ⌘R.

**Wrong live, now fixed:**
- **Crop:** the hidden cropped area left a faint frame (wrong pasteboard colour) and a pixel column at fractional zooms.
- **Focus:**
  - a blue focus ring appeared on the canvas;
  - keys were swallowed while a menu trigger had focus;
  - number keys did nothing after a tool switch;
  - ⌘2 opened Orion because focus stayed on the hidden design canvas.
- **History:** the source column was invisible because of CSS specificity.
- **Layers:**
  - the clip arrow pointed the wrong way;
  - groups showed "Normal" instead of "Pass Through".
- **Brush options:** Flow/Spacing/Smoothing showed f32 noise ("10.000000149011612").
- **Selections:**
  - a blue tint inside the ants: the default display was "Outline & overlay", and Photoshop shows ants only;
  - ⌘H (Extras) didn't hide selection edges. View › Show › Selection Edges now exists, and Extras governs it.

**Still open:**
- **Paths:**
  - the target path is drawn only while a path-selection tool is active;
  - no View › Show › Target Path (⇧⌘H).
- **Pen:** the options bar lacks Make: Selection/Mask/Shape and the path operations.
- **Crop:** no crop box appears when the tool is picked.
- **Adjustment layers:** no default white mask on new ones (needs an engine change).
- **History:**
  - the snapshot thumbnail is a placeholder unless the opening state is current;
  - no auto-scroll to the current state.
