## Revised direction

- Retain the accepted see-through Liquid recipe. Replace the heavy hardware reference with a fine translucent double rim, tiny faceted edge catches and restrained depth. No chunky chrome, opaque slab, animated bloom or added full-screen effects. These are illustrative CSS highlights, not real refraction of arbitrary live DOM.
- New original procedural sphere artwork, not Lucide app outlines and not mere colour swaps. Project 3D curves/vertices into a shared transparent orb body, depth-sort/deduplicate screen-space points; fine illustrative glass highlights remain behind the points. The creator-owned Orion app icon and current `OrionOrb.tsx` were inspected for the sphere/dot language; the installed thinking-orbs package was read, not installed, changed or copied into this prototype.
- **Archives:** stacked latitude/memory bands. **Orion:** meridians, diagonal orbit and inner core. **XDesign:** projected geodesic facets. **Command Center:** scan/equator structure. **Hermes:** paired woven paths. **Incubator:** nested seed/core structure. Clean-line utility icons remain quieter; app labels stay accessible on hover/focus.
- Dot radius `.4.. .48`, minimum separation `2.0` in the 32-unit glyph coordinates, versus first concept `.63` radius/`32/19` grid. Orbs display at 36px; these source bounds are not pixel-contrast or arbitrary-DPR acceptance claims. All six structures differ, and ink stays legible rather than reducing every alpha to near-invisible dust.
- Remove numbered/boxed slot styling; quieter centred state pips, 1px target-only hover lift, no fisheye or constant particle animation. Geometry generated/cached once, not a per-pointer/per-frame canvas loop. Existing simulated click/keyboard/layout/reduction controls retained.
