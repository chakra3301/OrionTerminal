# Orion Studio — public alpha 2

Orion Terminal is now **Orion Studio**: Archives 47, Orion and XDesign in one desktop, with your choice of supported AI providers.

## What changed

- Studio branding throughout the app, setup, help, settings, documentation and bundled notices.
- The approved glass app icons and generative skill identities, with animated orbs and dimensional glyphs. The original Rosie dock orb is retained.
- Updated XDesign image-editor controls and document workflows from the alpha development branch. The earlier image-to-3D experiment is removed; stored project data is retained.
- Refreshed release dependencies, including SQLite 3.54.1. The optional Cursor SDK is now pinned to 1.1.0; existing Cursor users should use Install SDK in Control Panel → Providers to update that separate runtime.
- The domain remains **orionterminal.app** and X remains **@Orion_terminal**.

## Download and upgrade

**Apple Silicon Mac only.** Download **`Orion-Studio_aarch64.dmg`** and compare `shasum -a 256 <downloaded-file>` with the attached `SHA256SUMS.txt`. The version-named DMG is the same installer under another name.

Quit the old app, open the DMG, and drag **Orion Studio** to Applications. The bundle identifier and existing data location stay the same. Confirm your saved work opens before removing the older Orion Terminal application. Keep a backup of important work.

This is the project's existing **ad-hoc signed, unnotarized personal alpha**. Use macOS's app-specific Open/Open Anyway controls only for a download you trust. Do not disable Gatekeeper.

[Install and provider setup](https://github.com/chakra3301/OrionTerminal/blob/v0.1.0-alpha.2/BETA.md). AI remains optional for local editing; subscriptions and API billing are separate.

## Alpha scope

Advanced FX, website reconstruction, specialist agents and untested provider combinations remain experimental. Accessibility, real historical-user recovery, collaboration and Intel support are incomplete. Databases and recovery files are unencrypted. Tool grants are not an OS sandbox; stopping a tool does not roll back completed side effects.

The new boot experience and standalone Archives 47 have separate development branches; this Studio installer preserves the current integrated startup and Archives app.

Third-party notices and required source materials are bundled. Imported content and optional runtimes retain their own terms.
