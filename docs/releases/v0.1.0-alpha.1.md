# Orion Terminal — public alpha

A personal workstation for **thinking, coding and design**: Archives 47, Orion and XDesign in one desktop, with Spotlight and your choice of supported AI providers.

## What's new

- Minimal first launch: a glass **Username** input, then **Password**. Arrow/Enter continues; the skip icon continues without sign-in. This is a local privacy gate, not encryption.
- Creator-made stock wallpaper, with animated overlays **Off** by default. Matrix and Core are optional in **Control Panel → Wallpaper**.
- Only **Archives, Orion and XDesign** enabled initially. Additional apps remain in **Control Panel → Plugins**; existing saved preferences/accounts are preserved.
- Quiet terminal-style `status : saved/unsaved` in the Archives titlebar, instead of a banner above the editor. Retry remains available.
- Provider-qualified AI routing, explicit account/billing choices, background AI off by default, safer saves, scoped recovery and bundled third-party notices/source.

## Download and install

**Apple Silicon Mac only.** Download **`Orion-Terminal_aarch64.dmg`** and `SHA256SUMS.txt` below. The other DMG is an identical version-named copy—you only need one.

Compare `shasum -a 256 <downloaded-file>` with the checksum, open the DMG, and drag Orion Terminal into Applications. Back up existing work before upgrading.

The app is **ad-hoc signed, not notarized**. Approve only a download you trust using macOS's app-specific Open/Open Anyway controls (Privacy & Security on newer macOS). Do not disable Gatekeeper; report an unexpected refusal instead.

[Install and setup guide](https://github.com/chakra3301/OrionTerminal/blob/v0.1.0-alpha.1/BETA.md).

AI is optional for local editing. Connect through **Control Panel → Providers** and select the intended provider/model. Subscriptions and API billing are separate; model and image availability depends on your account. Inline editing/Tab completion use the Anthropic API. Background AI starts off.

## Alpha limits

- Experimental: advanced FX/video/audio/shaders, img2model, website reconstruction, Hermes/Command and untested provider combinations.
- Accessibility/VoiceOver and real historical-user upgrade/recovery coverage remain incomplete.
- No Intel build, notarization, light theme or multiplayer.
- Databases, backups and recovery journals are unencrypted. Recovery is scoped, not a guarantee against every crash or power loss.
- Stop is not rollback; already-running tools may complete side effects. Tool permissions are not an OS sandbox.
- Original project code and creator-owned bundled assets use Apache-2.0. Third-party notices and matching MPL source are included; imported content and optional runtimes retain their own terms.

## Verification scope

The baseline `86ec7cf` passed [remote CI](https://github.com/chakra3301/OrionTerminal/actions/runs/34893323117). A recipient reported successful installation on a previously unused Apple Silicon Mac running Tahoe 26.6, core save/reopen/PNG export and ChatGPT onboarding/chat. The new setup/default logic subsequently had isolated native checks; the final minimal setup styling and Archives titlebar status have not had another human smoke test. Release automation checks the tagged source and builds these attached assets—not the older baseline DMG.
