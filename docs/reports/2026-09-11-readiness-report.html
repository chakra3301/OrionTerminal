01 / DELIVERED

What the polish pass actually changed

This was not just cosmetic cleanup. The most important changes address choosing the right account, listening to responses at the right time, and keeping one project's data from being overwritten by another operation.

AI routing and account identity

  • Selections now carry the provider identity, not just a potentially duplicated model name.
  • Disabled, missing, or ambiguous shared selections fail visibly instead of silently choosing Claude.
  • Stop targets the connector actually running—even if preferences change.
  • HTTP models receive enriched app context; live cross-connector switches drop incompatible sessions.
  • A global Default AI can be overridden per surface.

FX and learning are less Claude-bound

  • FX Assist uses the shared dispatcher, a model picker, Stop, and 10 MCP/runtime tools.
  • Shader generation uses the selected text model instead of requiring the Anthropic API.
  • Learn, Tutor, and RepoLens text analysis use shared model calls.
  • Malformed grading output no longer silently reduces mastery.
  • Cursor SDK receives Orion's MCP configuration; generated tool schemas have a parity test.

Two concrete img2model defects

Late listeners: the native send could finish before the frontend subscribed, causing a completed run to look like a timeout. Listeners now register first.

Overwritten references: comparison captures reused the reference's snapshot path. PNGs now get unique paths. Reference metadata persists; model changes autosave; cancellation cannot start another autonomous round.

These fix real defects; they do not prove every reported stall is resolved in a live session.

XDesign project and save safety

  • Project transitions, document saves, and registry writes are serialized.
  • Concurrent “ensure a project” requests create one project, not duplicates.
  • Switching is blocked during generation/import; the editor is inert during transitions.
  • Missing stored documents cause an error rather than silently becoming blank.
  • Transient canvas state no longer triggers unnecessary saves; failures are visible.

Native files, processes, and setup

  • Atomic saves use unique temporary files, preserve permissions, and clean up failures.
  • Imports have size/regular-file checks; IDs use real ULIDs.
  • Unicode truncation and early-cancellation signal loss were repaired.
  • CLI probes are bounded. TypeScript, Python, and Rust language servers are installed and detected.
  • Core Codex chat no longer copies rotating auth; Gemini's tool exclusion schema was corrected.

Repeatable verification and honest UI

  • Node 22.13+ is required, matching the Cursor SDK minimum.
  • Doctor and combined verification commands are available; CI runs the checks.
  • Release CI blocks high or critical production npm advisories.
  • Release devtools support was removed; the development command is debug-only.
  • Shared copy no longer assumes Claude or fabricates observations about unseen notes/files.
02 / THE AI QUESTION

Are all AIs first-class now?

In shared selection and routing, substantially more than before. Across the entire workstation, not yet.

“Equal treatment” should mean respecting the chosen provider, preserving the correct account and context, and stating unsupported operations honestly. It does not mean pretending every model has identical capabilities. Some current gaps are in Orion's transport integration—not a limitation of the underlying model.

ROSIE & cross-app behavior

06 / RECOMMENDED NEXT CHAPTER

Finish closure before expanding the feature surface.

The recommendation is a focused stabilization phase—not another redesign or a new app. The order below is proposed work, not a schedule already underway. There is no credible completion percentage or delivery estimate until the dependency and integration choices are scoped.

  1. Establish a safe evaluation baseline

    Back up real data. Inventory the dirty worktree so pre-existing work remains intact. Use scratch projects, confirm the new binary is the one under test, and complete the desired provider logins. Separate implementation defects from missing-account access.

  2. Close routing/auth and security correctness gaps

    Core routing, ownership, HTTP binding and native MCP denial have fixes and tests. Next: live connector/specialist acceptance, external account changes, filesystem races and remaining adversarial cases. Preserve the locked stack and do not bypass audit gates.

  3. Complete the AI coverage contract

    Decide and implement the intended behavior for Hermes, Command, inline editing, autocomplete, web lookup, and vision. Build a per-provider acceptance matrix rather than assuming every route supports the same operations.

  4. Close packaging, persistence, and resource lifecycle

    Cursor's managed installation passed. Verify broader distribution rights, full-profile recovery and orphaned-resource cleanup. Build a fresh package and DMG, then test without relying on the source checkout.

  5. Run the real acceptance sweep and land verified slices

    For each intended connector: stream, read, perform an approved edit/tool, cancel, switch, restart, and resume. Exercise all apps, exports, themes, and hostile-preview checks. Fix failures, rerun automation, and review/commit logical slices without sweeping in unrelated WIP.

What I need from you vs. what remains engineering work

Your involvement: authenticate the accounts you want supported; authorize any live tests that consume credits; confirm intended specialist exceptions and dependency/distribution decisions; visually evaluate the actual workstation.

Engineering responsibility: finish the code migrations and security boundaries, add regressions, remediate/review dependencies, make packaging self-contained for its supported features, and turn each smoke-test failure into a tracked fix. “Needs testing” must not become a substitute for doing the work.

Ad-hoc signing and no notarization are intentional for the personal release target. Commercial distribution, notarization, or a new marketplace is not being quietly added to this closure scope. Community-code distribution should not precede its stronger security requirements.
